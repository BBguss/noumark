# Keyboard shortcuts

## General

| Action | Shortcut |
|---|---|
| Command palette (files) | <kbd>Ctrl</kbd>+<kbd>K</kbd> or <kbd>Ctrl</kbd>+<kbd>P</kbd> |
| Command palette (commands) | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> |
| Open file | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| Settings | <kbd>Ctrl</kbd>+<kbd>,</kbd> |
| Reload from disk | <kbd>F5</kbd> |
| Close a panel / bar / mode | <kbd>Esc</kbd> |

## Reading

| Action | Shortcut |
|---|---|
| Find in document | <kbd>Ctrl</kbd>+<kbd>F</kbd> |
| Next / previous match | <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd> |
| Focus mode | <kbd>Ctrl</kbd>+<kbd>.</kbd> |
| Zoom in / out / reset | <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd> |
| Zoom with the mouse | <kbd>Ctrl</kbd>+wheel |

## Layout & appearance

| Action | Shortcut |
|---|---|
| Narrower / wider content | <kbd>Ctrl</kbd>+<kbd>[</kbd> / <kbd>Ctrl</kbd>+<kbd>]</kbd> |
| Cycle content width presets | click the width in the status bar |
| Toggle files sidebar | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| Toggle outline | <kbd>Ctrl</kbd>+<kbd>\\</kbd> |
| Cycle Auto / Light / Dark | <kbd>Ctrl</kbd>+<kbd>T</kbd> |
| Resize a side panel | drag its inner edge (double-click to reset) |

## Navigation

| Action | Shortcut |
|---|---|
| Back / Forward | <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd>, or the mouse side buttons |
| Jump to a heading | <kbd>Ctrl</kbd>+<kbd>K</kbd>, then type `#` |

## Editing

| Action | Shortcut |
|---|---|
| Edit a block | double-click it |
| Save block / cancel | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> / <kbd>Esc</kbd> |
| Toggle source editor | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| Bold / italic (source editor) | <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>Ctrl</kbd>+<kbd>I</kbd> |
| Indent | <kbd>Tab</kbd> (inserts two spaces) |
| Save now | <kbd>Ctrl</kbd>+<kbd>S</kbd> (saving is automatic anyway) |
